# Presentation application icons

These local assets are used only to identify third-party applications in DeckTap's quick-target picker. Product names and trademarks belong to their respective owners.

- `keynote.png`: Apple App Store Keynote artwork.
- `powerpoint.png`: Apple App Store Microsoft PowerPoint artwork.
- `wps.svg`: WPS official website logo asset.
- `propresenter.svg`: Renewed Vision official website icon asset.
- `perfectcast.png`: PerfectCast (极演投影) official website logo asset.

The files must remain bundled locally so the desktop renderer never loads remote images.
